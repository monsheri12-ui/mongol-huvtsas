# Хувцас

Игра для изучения монгольских названий одежды, обуви, украшений и цветов.

[Открыть игру](https://monsheri12-ui.github.io/mongol-huvtsas/)

106 предметов одежды, 32 названия обуви, 20 украшений и 8 аксессуаров. Два персонажа, 74 цвета и оттенка, 120 ситуаций для сборки образов, 12 историй вещей и свободная примерка.

## Запуск

Статическая игра без сборки и внешних библиотек. Для локального просмотра: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.

GitHub Pages: ветка `main`, папка `/ (root)`. Прогресс и альбом хранятся в браузере.

`embed.js` автоматически передаёт высоту игры родительской странице для встраивания в Тильду.
